## 문제

---

<p>두 정수 <code>a</code>, <code>b</code>와 boolean 변수 <code>flag</code>가 매개변수로 주어질 때, <code>flag</code>가 true면 <code>a</code> + <code>b</code>를 false면 <code>a</code> - <code>b</code>를 return 하는 solution 함수를 작성해 주세요.</p>

## 제한사항

---

```plaintext
- -1,000 ≤ a, b ≤ 1,000
```

## 입출력 예

---

```plaintext
a | b | flag | result

-4 | 7 | true | 3

-4 | 7 | false | -11

입출력 예

입출력 예 #1

- 예제 1번에서 flag가 true이므로 a + b = (-4) + 7 = 3을 return 합니다.

입출력 예 #2

- 예제 2번에서 flag가 false이므로 a - b = (-4) - 7 = -11을 return 합니다.
```


## 풀이 코드

---

### flag에 따라 다른 값 반환하기.cpp

```cpp
#include <iostream>
#include <string>

using namespace std;

//거짓 (False)인 경우 처리 함수
int False(int a, int b) {
    int answer = a - b;
    return answer;
    }

//참 (true)인 경우 처리 함수
int True(int a, int b) {
    int answer = a + b;
   
    return answer;
}

int solution(int a, int b, bool flag) {
    int answer = 0;

    return flag ? True(a, b) : False(a, b);
}
```
